# Omnichannel-Retail-Analytics-Dashboard
## Project Overview
Retail Sales & Inventory Analysis Datasets

This project contains multiple retail and e-commerce datasets designed for practicing:
	•	Data Cleaning
	•	Data Analysis
	•	Excel Dashboards
	•	PivotTables
	•	Business Insights
	•	Inventory Tracking
	•	Customer Analytics

The datasets simulate real-world retail operations and are ideal for beginner-to-intermediate data analytics projects.
